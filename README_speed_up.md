# 恐龙跑酷游戏 - 加速版本

## 项目概述

这是一个基于 GitHub 仓库的恐龙跑酷游戏的修改版本，添加了加速机制。

## 新增功能

- 游戏运行过程中，每隔固定时间（默认 10 秒）提升一次游戏速度
- 加速度表现为障碍物移动速度与恐龙游戏节奏整体加快
- 加速度速度值、时间间隔定义为可调节变量
- 页面上增加了显示当前游戏速度的 UI 元素

## 加速机制配置变量

- `SPEED_STEP`: 每次加速的幅度（默认 0.2）
- `SPEED_INTERVAL`: 加速间隔（帧数，默认 600 帧 = 10 秒）
- `MAX_SPEED`: 最大速度限制（默认 8，即基础速度的 2 倍）

## 修改的文件

### 1. index.html
- 新增速度显示的 UI 元素：`<div class="speed">速度: <span id="current-speed">1.0</span>x</div>`
- 该元素位于游戏头部，与分数和最高分显示并列

### 2. style.css
- 新增 `.speed` 类的样式定义，保持与分数显示一致的风格
- 新增 `#current-speed` 元素的颜色样式，使用蓝色表示

### 3. game.js
- 新增速度显示元素的 DOM 获取：`const currentSpeedElement = document.getElementById('current-speed');`
- 新增加速机制配置变量：`SPEED_STEP`、`SPEED_INTERVAL`、`MAX_SPEED` 和 `currentSpeed`
- 修改障碍物类的速度属性：将固定速度改为基于当前游戏速度的动态计算
- 修改游戏主循环中的加速逻辑：实现定期加速机制
- 修改重置游戏函数：确保游戏重新开始时速度相关变量正确重置

## 运行方式

1. 克隆仓库到本地
2. 切换到 speed-up 分支
3. 使用浏览器打开 index.html 文件
4. 点击开始游戏或使用空格键开始

## 游戏说明

- 使用空格键或点击屏幕让恐龙跳跃
- 避开路上的仙人掌障碍物
- 跑得越远，分数越高
- 游戏会记录你的最高分数
- 游戏速度会每隔 10 秒自动提升一次

## 加速机制实现原理

1. **定期检查**：在游戏主循环中，每帧都会检查是否达到加速间隔
2. **速度计算**：当达到加速间隔时，当前速度会增加一个固定的幅度
3. **速度限制**：为了防止游戏速度过快，设置了最大速度限制
4. **动态调整**：障碍物的移动速度会根据当前游戏速度动态调整
5. **状态更新**：速度显示 UI 元素会实时更新，显示当前的游戏速度倍数

## 可扩展性

加速机制的设计考虑了可扩展性：
- 所有配置变量都集中定义，便于后续调整
- 加速逻辑与主游戏逻辑分离，便于维护和扩展
- 速度显示元素的样式可以根据需要轻松修改

## 技术实现要点

1. **性能优化**：加速检查逻辑简单高效，不会影响游戏性能
2. **状态管理**：速度相关的状态变量得到了正确的管理和重置
3. **UI 反馈**：用户可以通过速度显示元素直观地了解当前游戏速度
4. **向后兼容性**：加速机制的添加保持了原有的游戏功能和操作方式
